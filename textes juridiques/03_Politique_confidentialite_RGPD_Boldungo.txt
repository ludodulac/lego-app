2. Données susceptibles d’être traitées

Selon les fonctionnalités utilisées :
- données de compte : nom ou pseudonyme, adresse email, identifiants techniques ;
- données de facturation et transaction, les données de carte étant normalement traitées directement par [PRESTATAIRE DE PAIEMENT] ;
- photographies transmises par l’utilisateur ;
- informations visibles dans les photographies : façade, environnement et, accidentellement, personnes, plaques ou autres éléments identifiants ;
- caractéristiques du bâtiment fournies ou déduites : dimensions approximatives, ouvertures, toiture et autres éléments architecturaux ;
- données de projet et résultats générés ;
- données techniques : adresse IP, journaux de sécurité, appareil, navigateur ;
- métadonnées de fichiers, qui peuvent contenir des informations de date ou de géolocalisation.

BOLDUNGO entend appliquer un principe de minimisation. Les métadonnées EXIF/GPS non nécessaires devraient être supprimées dès que possible.
