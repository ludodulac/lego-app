# BrickHouse deployment note

The production engine tracks `main` on Render. ArchitecturalScene v0.2 can project and build multiple rectangular volumes on one shared M0 stud grid. Gable roofs remain fully generated. Flat-roof volume walls are generated with an explicit compatibility warning until dedicated flat coverage lands; terraces, exterior stairs, chimneys, terrain profiles and facade equipment remain explicit Scene-to-M0 losses rather than silent simplifications.
